# Color Palette Generator

A web application that helps designers and developers generate harmonious color palettes based on a selected base color.
The app automatically creates color combinations using common color harmony rules, making it easier to explore visually balanced palettes for UI, branding, or design projects.

## Live Demo

https://color-palette-generator-five-kohl.vercel.app/

## Features

* Generate color palettes from a selected base color
* Support multiple color harmony schemes
* Real-time palette generation
* Visual preview of each generated color
* Easy exploration for UI and design inspiration

## Tech Stack

* React.js
* JavaScript
* Tailwind CSS
* Vite
* Vercel (deployment)

## How It Works

1. Select or input a base color.
2. Choose the desired harmony type.
3. The application generates a palette based on color harmony rules.
4. Users can explore and use the generated palette for design purposes.

## Installation

Clone the repository:

```bash
git clone https://github.com/boboiboyapi01/color-palette-generator.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Deployment

This project is deployed using **Vercel**.
